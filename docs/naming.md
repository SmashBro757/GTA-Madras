# Naming

**GTA Madras** is a working title. It matches the repository name. It is provisional: a plain description of the conversation that produced these notes, a GTA-like explorable city, with Chennai as the city. Venkat is uneasy about piggybacking on Grand Theft Auto branding, so the title stays open.

The subject is the city now called Chennai, and long called Madras. These notes do not decide which of those names the project should carry.

Changing the GitHub repository name is outside this documentation. The working title and the repository name can part ways later, once a name is actually chosen.

## Independence

This project is not affiliated with Rockstar Games. It is not Grand Theft Auto. It does not use that company's assets, stories, characters, or logos. Marks echoed by the working title remain the property of their owners.

Whether the letters "GTA" stay or go is an open naming question. These notes do not offer a legal conclusion about the working title.

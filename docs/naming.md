# Naming

**GTA Madras** is a working title. It matches the repository name. The name is unresolved. "GTA-style" in these notes means a genre and a fictionalized city, the kind of explorable fiction the idea points at. It does not mean borrowed assets, borrowed branding, or a claim on Grand Theft Auto. Venkat is uneasy about piggybacking on that branding, so the title stays open.

The subject is the city now called Chennai, and long called Madras. These notes do not decide which of those names the project should carry.

Changing the GitHub repository name is outside this documentation. The working title and the repository name can part ways later, once a name is actually chosen.

## Independence

This idea is not affiliated with Rockstar Games. It is not Grand Theft Auto. It does not use that company's assets, stories, characters, logos, or branding. Marks echoed by the working title remain the property of their owners.

Whether the letters "GTA" stay or go is unresolved. These notes do not offer a legal conclusion about the working title.

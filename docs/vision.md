# Vision

A compressed Chennai, geographically selective, and explorable. The hope is to catch the city's essence, character, and air. The visual ambition is realistic. Cartoon stylization sits outside that ambition.

The city is personal to Venkat. These notes exist so a later project has a chance of doing Chennai justice. A caricature would miss the point, even if it were immediately recognizable.

These notes claim no special rank for Chennai among cities. They invent no history. If the project later touches a temple tradition, a building, or a neighborhood's past, that material has to be real. Color made up for atmosphere is not an acceptable substitute.

## The range the city has to be able to hold

A selective map can still be false if it keeps only one Chennai. The selection is about range:

- the IT corridor
- older industry
- the beaches
- temples and devotional life
- cultural history
- historic buildings that are still standing
- family life as it is lived at different ages

Read the list as a statement about variety. Treating it as a map, a content schedule, or a promise would over-read it. No neighborhood has been chosen. No building has been designated.

Historic buildings, here, means buildings that still stand in the lived city. Rebuilding earlier coastlines, streets, and infrastructure as they changed through time is a different task, kept with the sister project below.

## Scale

The city in this project is smaller than the real one, and selective about which ground it includes. The limit is deliberate. Manageable is the goal.

Compression has a cost. Leave out too much, and the result is a postcard. Take in too much, and the work ceases to be makeable. These notes name that tension and leave it unresolved. The [references](references.md) are two other city efforts sitting in the same tension: one Venkat could already play, still rough; one described by its author as heavier production, still in progress.

## Aspiration and first proof

Experience-first remains the aspiration. Moving through the place should feel like Chennai before it feels like a list of systems.

That aspiration is not a gate on a public experiment. A showing does not have to wait until the feeling is complete, and it does not have to wait indefinitely for a finished city.

When any making starts, the first concrete step is a tiny explorable proof of concept. What it includes, and what "tiny" means in streets or minutes, is undecided. These notes are not that proof, and they set no date for it.

## Sister project

[Project Madras](https://github.com/SmashBro757/Project-Madras) is the linked sister project. As distinguished in these notes, it is a community effort toward a geographically grounded Chennai: the city as it stands, and a historical reconstruction in which time, terrain, and infrastructure change accurately.

This repository does not take up that brief, and it does not take up a one-to-one city. Compression here may omit streets, years, and systems. Where this project cares about accuracy, the accuracy is of a recognizable lived city.

The paragraph above is this project's boundary. It is not a quotation from the other repository, and it does not speak for that repository.

Both efforts are intended as open-source community projects. This repository has not chosen a license. Public visibility is not a license. The README states that directly.

## Opening tone

Venkat has suggested an intentional funny spawn for an early version, so a rough first play would set lighter expectations. The humor in that suggestion is nonpolitical, and it is about the unfinished build. It is not a joke at the city's expense. It is optional. It is not a decided requirement.

The suggestion sits beside his account of Hyd World in the [references](references.md): a rough but recognizable city, and an unscripted moment that was funny because nobody had written it. If anything from that account is worth remembering here, it is lightness about a rough build. That account's players, combat, and names stay in the account.

If an early version ever used that kind of opening, the further suggestion is to retire it in favor of a mature, polished opening. The thought is about tone. It has not been adopted, and it schedules nothing.

A separate idea was only tentative: a politically themed opening built around a chief-minister convoy associated with Vijay. Venkat flagged the risk of offense. It is not an approved feature. Political figures, parties, and convoys are outside this project.

## What these notes leave open

The name, the license, the tools, the map, and the scope of the first proof are all undecided. An open question is not a promise to settle it, and it is not a request to settle it by adding a game to this repository.
